# Alt Tracker — трекер пар альткоинов

Готовый проект. Всё, что нужно сделать вам — три шага ниже, копи-пастом, без программирования.

## Шаг 1. Supabase (база данных)

1. Зайдите на supabase.com → Sign up (можно через GitHub) → New project.
2. Придумайте пароль для базы (просто сохраните его куда-нибудь), выберите любой регион, нажмите Create.
3. Слева откройте **SQL Editor** → New query → откройте файл `sql/schema.sql` из этого проекта, скопируйте всё содержимое, вставьте и нажмите **Run**. Появятся таблицы users и pairs.
4. Слева откройте **Project Settings → API**. Скопируйте:
   - **Project URL** → это `SUPABASE_URL`
   - **service_role key** (не anon!) → это `SUPABASE_SERVICE_KEY`

## Шаг 2. GitHub (хранилище кода)

1. Зайдите на github.com → Sign up.
2. Create new repository, любое имя, например `alt-tracker`.
3. Загрузите туда все файлы из этой папки (кнопка "uploading an existing file" на странице репозитория — можно перетащить всю папку).

## Шаг 3. Vercel (публикация сайта)

1. Зайдите на vercel.com → Sign up **через GitHub** (это свяжет аккаунты автоматически).
2. Add New → Project → выберите репозиторий `alt-tracker` → Import.
3. Перед нажатием Deploy откройте **Environment Variables** и добавьте три переменные (значения смотрите в `.env.example`):
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_KEY`
   - `APP_SECRET` — придумайте любую случайную строку, например `mySecretKey12345xyz`
4. Нажмите **Deploy**. Через минуту сайт будет доступен по адресу вида `alt-tracker-xxxx.vercel.app`.

Готово. Открывайте ссылку, нажимайте "Зарегистрироваться" — система выдаст вам логин 00000001, дальше добавляйте пары через "+".

## Функции

- Регистрация/вход по логину-автоинкременту и паролю
- Список пар с ценами, соотношением, % изменения за 24ч (зелёный/красный) и мини-графиком
- Сортировка пар стрелками ▲▼
- Удаление пары ("–" справа от строки)
- Добавление пары через "+" (актив + биржа + необязательные пороги для Telegram-уведомлений)
- График соотношения пары: All / 1 год / 1 месяц
- Переключатель светлой/тёмной темы
- Адаптивная вёрстка под телефон
- Кэш цен (15 сек) и автоматический переход на резервную биржу при сбое основной
- Уведомления в Telegram при пересечении заданного порога соотношения

## Настройка Telegram-уведомлений (дополнительно)

1. В Telegram напишите **@BotFather** → `/newbot` → следуйте подсказкам → получите токен вида `123456:ABC-...`.
2. В Vercel → Settings → Environment Variables добавьте:
   - `TELEGRAM_BOT_TOKEN` = токен из BotFather
   - `CRON_SECRET` = любая случайная строка (защищает эндпоинт проверки от чужих запросов)
3. Redeploy проекта.
4. На сайте нажмите "Подключить" в баннере про Telegram — но сначала напишите вашему боту в Telegram что угодно (например "привет"), иначе бот не будет знать, кому писать.
5. Чтобы уведомления реально приходили, нужен внешний "будильник", который раз в несколько минут будет заходить на адрес:
   ```
   https://ваш-сайт.vercel.app/api/check-alerts?secret=ЗНАЧЕНИЕ_CRON_SECRET
   ```
   Бесплатный вариант — cron-job.org: регистрация → Create cronjob → вставить эту ссылку → интервал, например, каждые 5 минут.
